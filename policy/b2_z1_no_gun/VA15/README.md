# VA15：按 1 显示焊枪并启用物理碰撞

在仓库根目录启动，必须显式指定 VA15；通用脚本不带 `--profile` 时仍默认使用旧 v4：

```bash
bash scripts/run_b2_z1_v4.sh --profile policy/b2_z1_no_gun/VA15 --speed 0.22
```

也可以在 VS Code 选择“部署 VA15：MuJoCo 裂缝视觉（model_5000）”。

在启动程序的终端直接按键，无需回车：

1. 启动时趴下，焊枪隐藏，焊枪碰撞关闭。
2. 按 `0` 起立，等待终端提示 `Standing settled`；此时焊枪仍未安装。
3. 按 `1`，显示圆柱焊枪，同时恢复场景碰撞，随后机械臂进入策略开始姿态。
4. 显示 `ready` 后，按 `t` 切换轨迹跟踪与默认模式。停止跟踪不会移除焊枪。
5. 按 `9` 执行移除焊枪、折叠机械臂、趴下流程，焊枪显示与碰撞同时关闭。

未站稳前按 `1` 会被拒绝，不会提前安装焊枪。修改后的文件需要重启已有仿真才能加载。

焊枪使用已有 `welding_gun` 圆柱：长 1.10 m、半径 0.028 m，枪尖与 `ee_site` 对齐。
安装时碰撞掩码为 `contype=2, conaffinity=1`，用于与场景碰撞；保留原有机器人自碰撞设置。
圆柱 geom 本身质量为零，保留原模型连杆惯量和训练时 TCP 替代载荷，不通过安装操作改变质量。
