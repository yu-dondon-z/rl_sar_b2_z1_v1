## 改动

1. native 到本地 z1_controller 的 UDP 改为按完整回复授予一个发送机会。
   每次发送使用当前最新目标；不把中间目标排队。
   缺回复时不补发活动位置指令；转 PASSIVE 立即发送，不等待回复，
   之后仅对 PASSIVE 每 20 ms 重试一次。
   回复不被视为命令确认，不生成电机采样时间；原反馈失效和硬件故障处理仍生效。
   B2 写帧频率、映射和增益不变。
2. X/B、视觉拒收或再次 R1+Y 导致制动时，锁定停止前最后一次提交的机械臂参考。
   不重设为测量位置，不继续发送零速策略产生的新臂目标。
   腿部继续原减速与全站姿恢复；B 的后续收臂趴下仍保留。
   actor 的原始动作历史、权重和观测未更改。
   制动期间采用关节参考保持，不承诺移动机身上的 TCP 世界位置保持。
3. 前视先计算各连通分量在地面投影的距离下界，再提取可能胜出的中心线。
   对不可能胜出的远处分量跳过昂贵细化；保留原标签顺序平局规则，
   跨地平线无法证明距离界时仍完整处理。
   没有缩图、改概率阈值、填补缺失焊缝或修改相机时间。
4. 新日志包含 Python 提交起止、native 实际发给本地控制器的时间/来源时间/臂目标及计数。
   这些仍不是 arm 端接收或电机采样时间。
