# 前后视觉窗口与板载同步

`bash start_real.sh --interface eth0` 默认请求打开两个窗口：前 RGB、后 D435i RGB-D
的彩色图像。窗口显示已处理的同一对图像、检测中心线、原始帧号、主机收包年龄、
双视处理耗时，以及主程序实际状态和停车/等待原因。未新增枪尖检测或深度窗口。
无新图像时收包年龄继续增加，超过 1 秒标为 STALE，旧检测不会伪装成新检测。

请从**板载已登录的桌面终端**启动。SSH 的 DISPLAY 为空时会提示并继续无窗口运行，
不自动把登录界面当作用户桌面，也不设置任意 DISPLAY=:0。
通过 SSH 需要自行配置可用的 X11 转发；转发还会增加网络和显示开销。

```bash
cd /home/unitree/rl_sar_b2_z1_VD2
source .venv/bin/activate
bash start_real.sh --interface eth0
```

显示上限为 5 Hz，两路画面分别等比缩放并填边到 640×360。
复用相机与检测结果，不新增相机采集或模型推理。
独立 GUI 进程与深度为 1 的非阻塞队列隔离显示；拥塞时丢弃显示帧。
显示有少量缩图、进程间传输、窗口绘制与内存开销，不能声称完全不影响算力。
不需要窗口时使用 `bash start_real.sh --interface eth0 --no-display`。

Q、Esc 或关闭任一窗口只关闭两幅显示，不向机器人发送停止/运动事件。
手柄操作及终端 Ctrl+C 的既有语义不变；需要停车请使用原手柄操作。
窗口显示进程异常不会让视觉处理进程退出，终端会报告窗口已退出；
可捕获的错误另存本次 runs 目录的 `display_error.txt`。
GUI 进程发生原生库崩溃时，其退出码由主程序报告。
