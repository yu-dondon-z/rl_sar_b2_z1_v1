# D435i 异常配对恢复修复

2026-11-09：修复独立视觉处理在 RGB/深度时钟域不一致或时间差超过
40 ms 时退出整个视觉线程的问题。

异常组仅发布 valid=false、空几何及实际 RGB/深度时钟域、设备时间、时间差，
仍提供原始图像给窗口和诊断存储。后视继续等待下一组，前视独立更新。
下一组配对正常后恢复处理；原始采集时间不刷新，40 ms 与 1 秒限制不变。
其他不可恢复异常仍保留原有错误退出行为，不隐藏硬件或推理故障。

回归测试覆盖两类不匹配、连续异常、前视继续更新、无效结果不能通过
启动检查、窗口收到异常组图像，以及正常配对恢复。测试不启动设备。
不修改策略、增益、外参或状态机，无需编译 C++。

离线通过不等于实机相机已验证。现场先观察视觉窗口和日志；若仍无效，
查看 vision.jsonl 的 rgb_timestamp_domain、depth_timestamp_domain、
rgb_device_timestamp_ms、depth_device_timestamp_ms、rgb_depth_timestamp_skew_ms，
不要放宽阈值或把无效组当成有效几何。
