# 后视局部观测与 Z1 通信取证更新

更新 ID：`vd2_rear_observed_20261106`。基于 `vd2_front_local_20261106`，不需要重新编译 C++。
这是本地和板载离线验证的程序更新；实机连续行走、通信恢复与跟踪精度仍需现场验收。

## 原因和改动

15:45 会话中，tracking 约 1.92 秒后因后视三维路径不足 0.12 m 停车。
Z1 六轴 q/dq/tau 在此前约 0.56 秒已经停止更新，随后控制器报告机械臂 UDP 超时并转 PASSIVE。
这是两条独立故障链。未保存停车的第 57 包原始图像，不能把相邻有效图复算视为复现该包。

后视只需定位固定工作 x=-1.02 m 处的焊缝，统一套用前视的 12 cm 路径长度门槛不适合这个用途。
现在后视改为局部实测支撑检查：至少六个路径点，工作点每侧至少两个直接深度支持点，
每侧实际支撑至少 2 cm，最近两侧直接深度点的三维间距不超过 2.5 cm。
原神经置信度 0.90、直接深度比例 0.65、地面/前景排除条件继续使用。
不外推缺失工作点，不合成深度或更新旧帧时间。帧年龄 1 s、双路接收差 40 ms、后视保持 0.6 s 均沿用。
这些空间门槛是本次候选的明确工程条件，不能替代实机标定和误差测量。

控制触发视觉停车时，主进程请求相机进程保存导致停车的原帧。
相机进程最多缓存四对已发布图像，仅用于诊断；写盘仍由原有异步单槽线程完成。
保存 `visual_stop_000_*`、递增编号，包含 RGB、原 JPEG、毫米深度预览、未量化的原深度 `.npy`、
原始独立时间/帧号、失败视觉包和控制拒绝原因。缓存已淘汰时明确记录 missing，不以邻近图替代。

`z1_reply_age_ms` 明确表示板载 SDK 到本地控制器的回复年龄。
日志增加 `z1_controller_reply_age_s`、`z1_motor_sample_age_s=null`、`z1_motor_freshness_known=false`；
保留旧 `z1_age_s` 字段兼容分析。电机向量完全重复超过 0.2 s 且仍报告 >0.05 rad/s 时，
输出一次诊断并记录重复时长；这个诊断不改控制状态、不冒充电机采样年龄，正常静止不报警。

启动器新增 `main_events.jsonl` 与 `z1_events.jsonl`，保存每一条原输出及主机读到它的单调时钟。
这不是控制器内部事件或电机采样时刻。原始 `.log` 仍完整保留；实际 `z1_arm` 超时不会被折叠隐藏。
`launcher.json` 保存起止墙钟/单调时钟对应点，用于与 pcap 时间对齐。

## 一个终端采集机械臂通信

在板载现场执行。下面入口会启动控制器和主程序，机器人仍按原 A/Y/R1+Y 操作；
更新安装或离线检查不会执行这些命令。

```bash
cd /home/unitree/rl_sar_b2_z1_VD2
source .venv/bin/activate
sudo -v
bash start_real.sh --interface eth0 --capture-z1-network
```

`sudo -v` 仅预先获得系统抓包权限；只有 tcpdump 使用 sudo，主程序不提权。
抓包过滤器是 `udp and host 192.168.123.110 and port 8881`，记录真实双向 UDP，
保存到当前启动器目录 `runs/launcher_*/z1_arm.pcap`。抓包未成功启动时，启动器不会再新启控制器或主程序。
退出时先关闭主程序，再关闭自己启动的控制器，最后关闭抓包并写出统计；原来已在运行的控制器不会被杀掉。
中途抓包失败仅明确报告取证缺失，不改变机器人状态。

不能由“SDK 回复很新”推断电机通信正常；也不能仅由“q 不变”断言丢包或供电故障。
需要将故障时 pcap 的发包、收包与带时间的 `z1_arm` 超时和 q/dq/tau 对照，
再区分板载未发、机械臂未回、链路丢包或已返回但电机数据不更新。

## 离线复算

```bash
python run.py --offline-check
python tools/replay_front_path.py --session runs/实际会话目录 --prefix visual_stop_000_ --iterations 3
```

复算优先使用未量化深度文件；旧日志只有毫米 PNG 时继续支持，并报告 `exact_depth=false`。
使用原始采样时间，在历史时钟上评价，不把历史图送入实时控制。
复算不初始化相机、DDS、SDK 或运动。不能用常规 MuJoCo 通过证明实机 Z1 通信故障已经修复。

策略、起立/趴下流程、执行器增益、外参和机器人控制代码保持本更新前的哈希；
本更新仅修改后视局部有效性和诊断记录。仍没有实际枪尖视觉闭环，不能声称达到地面投影 5 cm。
