# VA15 V2.4.9：机身纠偏与后向 TCP 跟踪

2026-10-26 独立候选版，保留 V248 和主程序。开发/释放状态以 qualification.json 为准；同步和离线检查不启动任何实机控制。

## 本次修改

1. **机身纠偏**：当前相机几何分开给出横向偏差和路径方向。去掉“视觉角度减去无滑动估计侧滑角”的命令通道，避免录像对应日志中的转向抵消/反向。侧滑角仍记录，但不再影响转向。
2. **消除持续偏移**：增加有界、抗饱和的视觉误差积分，每次明确启步时清零。保持原有前进 0.15 m/s、转向上限 0.06 rad/s、滤波和斜率限制。没有开放未验证的横移命令。
3. **历史路径缓存**：相机每帧用于当前机身纠偏；后方 TCP 的缓存按实际位移/偏航/时间稀疏保存，最多 256 条、90 秒。解决慢速行走时按帧数淘汰过快的问题。相机捕获时刻仍与本体局部位姿同步。
4. **TCP 真实接入**：只取实际前视观测后保留下来的路径段。允许在原训练范围 x=[-1,-0.55]、y=[-0.15,0.15]、z=[-0.55,-0.30] 内沿已观测段分配目标，默认仍优先 x=-0.775。不是把超范围轨迹强行裁成另一条线，也不生成没看见的后方路径。
5. **平滑接入和可检查性**：维持原 4 秒混合、XYZ 速率上限 [0.04,0.04,0.02] m/s，确认真实历史接入后才向原训练的约 9 cm 目标离地高度缓降。终端与 CSV 区分“历史还没到后方”和“已到但超工作空间”；CSV 新增实测关节 FK 的虚拟延伸 TCP、目标及误差。

TCP 指的是 Z1 末端向下延伸的虚拟焊缝枪尖端，不是机械臂裸法兰。没有枪/软管时仍使用这个虚拟坐标点，不会虚构负载或碰撞。单目平地投影、IMU/关节无滑动局部里程计不是深度、全局定位或硬件合格证明。

- A 起立、Y 待机、R1+Y/T 启停、X 停止、B 停止并趴下、实际 Passive 趴稳后 Ctrl+C。
- 无额外窗口 R、静态审查步骤、短走定时器、固定距离或单次机会；恢复视觉不自动重启。

## 手动测试入口（须已释放并完成板载离线检查）

板载 NoMachine 桌面终端：

```bash
cd /home/unitree/rl_sar_b2_z1 || exit 1
bash diagnostics/va15_body_tcp_v249_20261026/run_visual.sh eth0 --walk
```

无枪/软管、旧控制退出、场地清空后，输入大写 RUN → A → 实际站稳后 Y → 确认窗口对应正确胶带 → R1+Y。

初次启步不会立刻用未知的后方地面驱动机械臂。前方看见的路径需要实际走到后方才会使 TCP_flat_floor=1 active=1；之前保持默认目标，日志打印原因。接入后目标缓慢变化，禁止为追求“马上 active”伪造历史。

用 X 停止、B 趴下；确认实际趴稳和 Passive 后 Ctrl+C。现场发现持续偏离或异常动作应人工停止，离线通过不代表实机验证完成。
