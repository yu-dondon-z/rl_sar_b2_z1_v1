# VA15 V2.4.8：修复反光导致的视觉路径截断

2026-10-26 独立版本，保留 V2.4.7 和既有主程序。没有新加按键、静态检查、行走次数/距离/短时限。

## 修复内容

本次实测中网络仍以约 98%～99% 置信度识别胶带，但瓷砖反光使原 RGB 黑色区域变窄或消失，远段提取连续四行失败，将路径截成 198/186/168 px，触发既有 500 ms 时效停车。

本版优先沿用原强 RGB 结果；只有原远段没有合格候选时，在**已验证的同一条近处胶带**上允许当前图像的弱对比度与高置信网络联合恢复：

- 当前 RGB 仍须有至少 10% 的局部对比度，网络置信度至少 97%、区域覆盖至少 85%。
- 沿用原来的宽度、预测位置、斜率和 ROI 约束；不会缩窄强 RGB 区域来逃避原有形状检查。
- 不使用历史像素假装本帧看见，不跨越完全空白区域，不外推隐藏路径，不改近点获取与身份关联。
- 路径仍至少 200 px；没有简单降低这个门槛。窗口和逐帧记录新增 recovered 行数，便于核实反光恢复是否生效。

VA15 权重、网络权重、输入尺寸、相机标定、C++ 控制/TCP/终点停止代码、增益、足端和 X/B 逻辑均不变。只有 Python 的远段提取、版本标签、窗口诊断和验证脚本改变。

## 使用

在板载 NoMachine 桌面终端执行，相机与 Z1 同入口：

```bash
cd /home/unitree/rl_sar_b2_z1 || exit 1
bash diagnostics/va15_visual_reflection_v248_20261026/run_visual.sh eth0 --walk
```

保持无枪/软管、旧控制已退出，输入大写 RUN → A 起立 → 实际站稳后 Y → 机械臂和支撑就绪、确认 PATH IN RANGE 对应正确胶带 → 一次 R1+Y 开始。无需窗口 R、第二终端或额外静态检查。

持续运动直到视觉确认线尾、R1+Y/X/B 或真实失效；无固定短走上限。X 停止，B 停止并趴下，实际趴稳且显示 Passive 后 Ctrl+C。恢复视觉不会自行恢复运动；停车完成后可明确 R1+Y 重启，不是一次机会。

前视确认线尾即请求原有受控站立停车，不要求后方 TCP 精确到达线尾，可能提前停。普通丢线/断流仍保护停车，不当成正常完成。遥控急停和人工看护仍需保留。

## 验证和边界
