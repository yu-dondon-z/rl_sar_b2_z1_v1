# V254：后方 TCP 视觉线尾修复（离线候选）

2026-10-27。目标：**后方 TCP 到达真实裂缝线尾，再停车站立**，而不是前相机看见线尾就停。

本目录独立于 V251、V252、V253，保留主程序及其他帐号的修改。策略仍为 VA15 model_5000。**本轮未访问、同步或启动实机。**

## 修复内容

1. 对照实际权重对应的训练归档，恢复训练时的受限目标分配。优先跟踪可达的真实观测段；暂不可达时，在有限恢复范围内分配平滑的训练工作区参考，同时保留未经裁剪的真实目标。不能把受限参考当成已经到达裂缝。
2. 真实线尾仍可见时，继续用同轨迹、时空一致的独立图像更新其局部位置；利用固定线尾的相对观测估计有限里程计尺度，减小线尾离开视野后的累计误差。
3. 修复四足支撑停车时，规划参考极小越界导致无法捕获的情况。仅将最多 0.02 rad 的规划参考超量投影回原有包络，实际支撑、接触、速度、姿态与力矩条件不变。
4. 保留此前的视觉减速请求、B/9 抢占与趴下意图锁存。新增真实目标/受限参考/误差/尺度/停车拒绝原因日志。
