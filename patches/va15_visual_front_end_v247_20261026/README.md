# VA15 V2.4.7：前视确认裂缝结束后站稳停止

2026-10-26 独立实验候选。保留 V2.4.5、V2.4.6 和主程序，当前放行与指纹只看本目录 qualification.json、BOARD_SYNC_REPORT.md；其他继承报告是历史资料。

## 本版目标

人工按 R1+Y 开始后，沿当前视觉胶带/裂缝连续行走；**前置相机确认这条线已经结束，就请求原有减速、支撑捕获、站立停止流程**。不设置四秒或短距离行走上限，不自动趴下，也不自动恢复行走。

这不是后方 TCP 的精确终点到达控制。相机在前方看见线尾时就会停车，因此机器人、后方 TCP 可能尚未到达物理终点。V2.4.6 的不可见尾段继续运动与精确终点逻辑未启用，不通过修改它的放行记录来规避其未通过的验证。

## 判断逻辑

1. 末端只取当前已关联曲线的实际观测远端点。要求原来的路径长度、置信度、宽度、身份关联、相机时效全部有效，不能把视野/ROI 边缘当成线尾。
2. 检查线尾前方的真实 RGB 背景与网络结果；有继续的黑线、长断口后的延续、明显遮挡/高光或不明确背景时，不宣称正常结束。不把外推点加入路径。
3. 原生端连续至少六个新帧、覆盖至少 0.5 秒确认同一条线的可见末端，才请求停止。重复读取同一包不增加帧数，末端跳变或证据中断会重置确认。
4. 最终只有原有停止控制器 Ready 且当前支撑静止持续 0.5 秒，才记录 VISUAL END STOPPED。没有绕过足端、通信、状态或停止判断。

普通失线、遮挡、相机断流和真实故障仍触发原有保护停车，**不计作正常完成**。仅凭 RGB 不可能区分真实线尾与完全同色、完全遮住延续的物体，因此仍需人工看护，不承诺任意现场都能识别终点。

## 保持不变

VA15 model_5000、70 维观测/18 维动作、raw/EMA、关节路由、增益、起立/Y 待机、首帧力矩接管、足端和原有停止流程不改。视觉前进 0.15 m/s、yaw 限制 ±0.06 rad/s；500 ms 图像时效与原有自动失效停车不改。

TCP 继续使用已观测历史、单目平地投影和实验性 IMU/关节无滑移局部估计，目标接入原始全身策略；不是深度相机、绝对定位、IK 覆盖或独立机械臂控制。未看见的后方路径不伪造，保持训练约 9 cm 目标，不强制 1 cm 接地。

## PC4 人工实验

在 NoMachine 桌面终端中运行，相机和既有 Z1 服务同入口：

```bash
cd /home/unitree/rl_sar_b2_z1 || exit 1
bash diagnostics/va15_visual_front_end_v247_20261026/run_visual.sh eth0 --walk
```

保持无枪/软管，B2 实际趴稳、旧控制程序退出，机械臂收回与行走区域清空，防跌和遥控急停措施就绪。输入大写 RUN → A 起立 → 实际站稳后 Y → 等待机械臂准备、支撑就绪 → 确认黄/青轨迹在正确胶带上且持续 PATH IN RANGE → 按一次 R1+Y 开始。

不推摇杆，持续看护。看到确认线尾后程序请求减速并站稳，VISUAL END SEEN 表示请求停车，VISUAL END STOPPED 才表示原有支撑停车完成。没有固定短走计时。可随时再次 R1+Y 或 X 停止；B 停止后趴下；只有实际趴稳并显示 Passive 后才 Ctrl+C。图像恢复不会自行重启；停止完成后需明确再次 R1+Y。

--preview 只开相机；--shadow 会接管站立但不给行走，不是只读模式。P/L1+X 撤去主动支撑，不是日常停车。不要用强退或断电代替站立时的受控停止。
