## 已修复的确定问题

V2.4.1 实测中的三次起步，先将小腿 Kp 从 675 切到 160，而旧起步偏置只保持 q_des，导致约 76% 请求支撑力矩丢失。首批 actor 结果返回前也存在低增益、旧目标的空档。

本版在新结果返回前完整保持旧指令；结果到达后按同帧 q/dq 计算旧指令的请求力矩：

    tau_old = kp_old * (q_des_old - q_actual)
              + kd_old * (dq_des_old - dq_actual) + tau_ff_old

在训练增益下计算等效静态目标：

    q_equivalent = q_actual + (tau_old + kd_policy * dq_actual) / kp_policy
    offset = q_equivalent - q_first_policy
    q_sent(t) = q_latest_policy(t) + (1 - smoothstep(t / 1.5s)) * offset

腿部仍使用训练的 Kp=160/Kd=5，dq_des=0、tau_ff=0，不额外叠加一份 PD 力矩，不删除 gyro 观测，不修改 raw 上一动作或 EMA。位置目标允许等效转换，保证的是切换时请求 PD 力矩连续，而非位置数值相同。

超出既有目标/力矩范围或输入无效时，保留最后有界命令，请求原支持停止；不伪造四足接触、不自动重启。首帧后不能保证物理输出力矩“完全不变”：实际电机反馈、阻尼及负载变化仍需实测。

初次尝试的“站立增益逐步降低但原样执行完整策略动作”变体，闭环仿真出现失稳，已排除，未部署。最终版本不在高站立增益下执行完整迈步动作。

## 尚未解决、不能宣称已解决

1. 实机连续微振：在理想 MuJoCo 的 0.15 m/s 稳态对照中，gyro_z RMS 约旧版 0.01613、新版 0.01586 rad/s，高频分量基本接近。因此本版修复的是确定的接管断层，不能证明真实约 6 Hz 晃动消失。真实电机/负载响应、IMU 闭环、摩擦仍需后续无视觉记录分离。
2. 关节目标—实测误差不能直接等同于电机故障：实测小腿平均误差约 0.279～0.309 rad，对应平均承载力矩约 44.7～49.6 Nm；PD 承载本来就需要位置误差。去均值后仍有 0.135～0.162 rad 波动，但正常运行的仿真也有明显目标变化，需结合实际机身振幅与运动效果判断，不能仅凭 RMS 提高增益。
3. 视觉推理延迟、500 ms 年龄预算和运行中六帧重新获取语义冲突，本版没有修改。最终视觉闭环使用合成图像点，不能证明真实分割流水线的持续性；本候选视觉行走暂未放行。
4. 没有枪和软管，未评估带工具的碰撞、质量或外力；Z1 在本地物理测试中仍使用既有内环代理。
