## 曲线起步

V249 用前视曲线的切线反推脚下 x=0 偏差。在实测弯曲胶带上，这个未观测的量与前视航向对抗。V250 不再做这个反推：

1. 尚无脚下历史时，按当前实际观测到的前向路径引导。
2. 历史实际覆盖机身 x=0 后，才使用已观测中心点，并平滑加入中心偏差积分。

只在真实历史段内插，不延长路径到看不见的后方。接入权重在 2 秒内渐变；现有 0.15 m/s、±0.06 rad/s、转向滤波/斜率、视觉时效和身份关联均保留。

## 停车收姿

V249 的捕获阶段把大于 0.6 rad/s 的纯偏航瞬态当成永久故障，导致未完成收姿的非对称目标一直保持。仅冻结或跟随实测关节姿态也在新物理测试中失败，因此最终方案不使用这两种方法。

在状态新鲜、支撑/高度有效、机身仍直立时，纯偏航瞬态不再永久锁住捕获姿态，而是继续**原有固定站姿恢复、动态力矩衰减和站立阻尼恢复**。策略始终关闭，不能重新行走。只有原有四足、速度、角速度、关节速度/漂移全部合格并持续 0.5 秒后，才允许完成站立停车或执行此前明确请求的 B 趴下。

真实失联、无效数据、明显倾斜、较大的滚转/俯仰角速度及电机故障仍拦截。不伪造接触，不放宽足端门限，不用超时授予趴下权限。
