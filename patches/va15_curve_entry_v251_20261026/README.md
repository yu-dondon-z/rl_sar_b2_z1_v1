# V251 / V2.5.1：仅使用真实观测路径的近前视引导

2026-10-26，独立候选。保留 V250、V249、主目录配置和可执行程序。用户已授权同步至板载独立目录，但没有授权自动启动实机。

## 改了什么

V250 修复了用前方弯曲路径切线向后外推脚下位置的问题，但其当前帧的远前视参考仍可能越过一个弯峰：机器人刚进弯，较远参考已经要求出弯，导致起步偏移。此问题在同一 VA15 actor 的物理仿真中可复现。

V251 的机身前视选择：

1. 必须仍有当前、同会话、合格且新鲜的视觉帧及有效局部位姿。
2. 从新到旧查找已实际拍到的曲线段。若某一段确实覆盖机身前方 x=0.60 m，则只在该段内插取前视点。
3. 如果这个近处尚未被看见，使用当前帧已观测路径中最近的前方点，不从远处切线反推它，也不连接不同帧之间的空缺。
4. 用这个点的实际方位角引导。超出原有角度包络时仍按超限处理，不能偷偷退回可能指向相反方向的远处像素点。
5. 实际历史覆盖机身 x=0 后，沿用 V250 的中心误差/航向反馈，2 秒渐变接入。

这里的 0.60 m 是控制的前视距离，不是固定裂缝终点，不是伪造出的路径点。没有覆盖它的实际观测段就不使用它。前视点和后向 TCP 的选择仍分开，不能用枪尖距离削弱机身纠偏。

## 保持不变

- VA15 model_5000、70/18 布局、归一化、原始动作历史、EMA、关节顺序与现有增益。
- 0.15 m/s 前进上限、±0.06 rad/s 转向上限、原转向斜率和滤波；没有通过增加速度/转向或放宽评分取得通过。
- 视觉网络/分割、胶带关联、反光恢复、帧时效、接触判定和真实电机故障拦截。相机代码仅更新版本提示。
- 局部 IMU/关节无滑移估计仍未取得硬件资格；估计出的 course_slip 只记录，不用于转向。
- V250 的偏航瞬态停车收姿修复：恢复固定站姿，而不是永久冻结未完成姿态或跟随实测关节丧失刚度；原站稳条件满足后才可趴下。
- TCP 是虚拟焊缝枪延伸尖端，不是裸机械臂法兰。仅在后方真实历史到达且原训练工作空间可达时接入，目标速率限制不变，目标离地高度渐变至训练中的约 9 cm。
- 视觉确认真实线尾后请求站立停车；丢线是保护停车，不是正常终点。当前不是后向 TCP 到达最终端点的精确收尾。
- A 起立、Y 待机、R1+Y/T 明确启停、X 停止、B 停稳后趴下；没有增加窗口 R、短走定时、距离或单次机会限制，也不自动重启。

## 可观测性

新增终端/CSV 字段：visual_preview_valid、visual_preview_history、visual_preview_x_m、visual_preview_y_m、visual_preview_age_s。它们明确表示前视点来自当前帧还是旧观测段；body_reference_history 另行表示脚下历史，不能混同。
