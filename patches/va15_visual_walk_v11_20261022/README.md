# VA15 近场识别修复 v1.1 — 2026-10-22

当前只开放相机预览和零行走命令联调。`--walk` 保持锁住，需先检查真实站姿原图，不因单元测试通过而放行运动。

本次修正：RGB 胶带区域与神经网络广泛支持相结合，避免反光把胶带中心拆成左右两条；图像宽度采用经存档确认的 12～180 原生像素范围（原 80 上限误拒了 117～144 像素胶带）。网络置信度、停止/足端和电机门槛不降低。

这是独立候选，不覆盖正式脚本、V2 实机程序、VA15 权重或配置。未自动起立、接管或行走。

## 范围与限制

- 模型仍为 VA15 model_5000，70 维观测、18 维动作，原始动作历史、0.20 EMA、关节映射不变。
- 四足与机械臂仍由原全身策略控制；本阶段不把网络识别结果同时写入 TCP 目标。
- 相机仍为 B2 自带前光学 RGB，通过 FrontVideoClient 获取 JPEG；不是 RGB-D，也没有使用深度。
- 在图像下部 77%～97% 搜索，只使用最近 120 像素左右的连续黑色线前缀；固定检测锚点仍在图像高度的 90% 处，结合宽度、明暗对比、网络置信度、连续性和时序关联。远端红点/分叉不参与转向。
- 输出是**近场方位角**，不是米制轨迹、世界坐标、里程计或 TCP 历史路径。
- `yaw_target = clip(1.2 * bearing, ±0.06 rad/s)`，时间常数 0.4 s，变化率不超过 0.04 rad/s²。
- 行走候选只请求前向 0.15 m/s，侧向为零，每进程一次、最多 4 秒单调时钟正向请求；原策略的速度加减速限制仍在。
- 四秒是命令请求预算，**不是实际停稳时间或距离保证**。失线、换线、手柄偏移、X/B、状态异常会撤销请求并锁存停止，不自动重启。
- 原电机健康检查、实验性支撑估计、起步/停止门槛及并行趴下流程保留，没有伪造足端接触或降低阈值。实验估计不是硬件认证。
- 时间戳是本机收到相机 JPEG 后的单调时钟，不是曝光硬件时间戳；不能据此宣称完成图像/IMU 的曝光同步。

## 已做的离线检查

详见 `qualification.json`、`outputs/regression_frozen/summary.json` 和 `outputs/functionality_frozen/summary.json`（完整仿真输出保留在开发电脑）。

- C++：电机契约、诊断队列、近场视觉入口/停止/防重放、原试验监督器。
- Python：薄缝/低置信度拒绝、远端分支隔离、换线拒绝、会话隔离、零输出联调证据检查。
- 34 种原停止/故障/摩擦/负载估计扰动回归。
- 16 项全身功能/视觉合成反馈仿真：待机、前后左右、小幅左右转向、小幅 TCP 目标变化、近场直线/缓弯、失线、无效帧、X 停止及不同摩擦。

注意：软件不变量通过不等于每种运动能力通过。固定当前 TCP 配置时，后退和左右平移位移不足；不因此开放这些实机方向。近场视觉 4 秒直线仿真仍有厘米级横向误差，TCP 位置 RMS 约 0.10 m，不能当成焊接精度或全功能视觉跟踪验收。合成相机数据不证明真实分割正确。

`offline_vision.py` 只回放存档图像，不连接相机/机器人。重复同一图像不能成为六帧启动证据；带有旧可视化标记的存档图像也不适合作为分割精度真值。

## 板载操作：先零输出联调

在 **PC4 的 NoMachine 桌面终端**，不另开 Z1 控制窗口。不要同时运行旧控制程序。

```bash
cd /home/unitree/rl_sar_b2_z1 || exit 1
bash diagnostics/va15_visual_walk_v11_20261022/run_visual.sh eth0 --shadow
```

开始条件：B2 已实际趴稳、旧控制退出、无枪/软管，手柄归中，收臂路径和周围空间清空，并具有可靠的防跌倒保护及已验证的急停方案。

1. 相机先打开；趴卧时 `INVALID` 不妨碍静态起立。只有收到实际可解码的原始分辨率图像才启动后续确认。
2. 阅读提示，输入大写 `RUN`；等待 `[Motor contract] ready=1 latched=0`，按 **A** 起立。
3. 站稳后确认画面**近处黄色点**是目标胶带。站稳且 Y 待机完成后，在**相机窗口**按 **R** 显式重新选线，清除趴卧视角关联；等待约 3 秒。R 会立即发布无效帧；行走中按 R 会停止，不能悄悄换线。
4. 胶带应在机器人前方接近正中间，画面显示 `NEAR LINE` 而不是 `NOT CENTERED`。不要为了绕过检查改极性/阈值。
5. 回到控制/遥控器，按 **Y**；等待暖机和静态支撑就绪，再按 **R1+Y**。本模式记录 `would_x/would_yaw`，实际速度始终为零，不执行策略推理行走。
6. 等四秒结束，按 **B** 趴下。确认**实际趴稳且终端显示 Passive**后再 **Ctrl+C**。相机随会话退出，不结束独立 Z1 服务。相机窗口按 R 时会保存 `exchange/standing_reset_raw.jpg`，该图不含标记；拒绝统计和原因写在 `near_guide.json` / `vision.log`。
7. 把开头 `Session records:` 的完整目录给出，或执行下列只读审查：

```bash
python3 diagnostics/va15_visual_walk_v11_20261022/review_shadow.py \
  /home/unitree/rl_sar_b2_z1/outputs/va15_near_shadow_实际目录
```

审查要求同一候选、最近一小时、完整 A/Y/B/Passive、连续四秒新鲜视觉、实际零速度且零推理输出、单调时钟期限正常结束、无丢失记录，以及相机负载下的写入/控制间隔、状态新鲜度、电机健康通过。实际黄点是否跟对胶带仍需人确认，程序不会把绿色识别当成真值。
