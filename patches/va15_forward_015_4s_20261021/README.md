## 本次唯一运动行为变化

- 专用试验中，摇杆前推是“按住触发”：接受后请求固定 **0.15 m/s**，不再
  因轻推而一直只给 0.07 m/s。它不是日常遥控模式中的隐藏最低速度。
- 仍通过原 0.18 m/s² 加速度限制逐渐提高 actor 命令，不跳变到目标速度。
- 单次正向请求最多 **4 秒真实单调时间**；控制积分预算也为 4 秒，先到者停止。
  4 秒包括加速/接管时间，不是物理停稳时间保证；减速/捕获可继续耗时。
- 放杆、X、B、非前向输入、反馈健康丢失或截止均锁存停止。B 另请求在支持
  判断成立后趴下；不绕过支持条件。一次进程仅允许一次运动请求，不能用
  持续推杆或再按 Y 自动重启。
- 禁止侧移、后退、转向和视觉。原来 1.5 秒腿部、2 秒机械臂接管未缩短，
  原增益和安全门槛未改变。

独立估计仍基于平地、无共同打滑等假设，不是校准接触传感器。
`hardware_qualified=false`；`sport_fresh=false`；原生产 validated 标志仍为 false。
不制造桥路值、不忽略 lost、不以超时作为停稳/卸力许可。

## 操作：仅板载交互终端

前提：机器人实际趴稳，旧控制程序已退出；没有枪或软管，收臂及前向区域
净空，具备可靠防倾倒保护和已经验证的急停方式，现场有合格操作者监护。
缺少这些条件时只运行 offline-check，不运行 forward-test。

```bash
cd /home/unitree/rl_sar_b2_z1 || exit 1
bash diagnostics/va15_forward_015_4s_20261021/run_trial.sh --offline-check
bash diagnostics/va15_forward_015_4s_20261021/run_trial.sh eth0 --forward-test
```

1. 阅读提示，条件满足才输入大写 `RUN`；Z1 自动启动/复用，不需第二终端。
2. A 起立。站稳后 Y 待机，保持摇杆回中，等 `[Restricted trial] armed`。
3. **不按 R1+Y。** 沿前向轻推并保持；接受后目标即为 0.15 m/s，仍缓慢爬升。
   只要姿态稳定，可观察至自动截止（最多 4 秒）。出现明显横晃、蹭地失衡或
   机械臂异常，立即松杆或 X 请求停止，不必等限时结束，不反复推杆。
4. 松杆/截止后等待实际停止，B 趴下；实际趴稳且显示 Passive 后 Ctrl+C。
5. 一轮结束不要继续推动来试第二次；若需复测，先安全趴下退出，再讨论记录。

4 秒不是物理停稳保证。故障可能使捕获/下降被拒绝；不要绕过门槛、站着
Ctrl+C、断电或杀进程来当作正常趴下。P/L1+X 是紧急被动，可能撤去支撑，
须按现场已验证的应急流程使用。
