## 修改了什么

1. 仅在锁存 B 请求后，将内存中 XY 命令减速从 0.12 调为 0.30 m/s²。
   普通减速及源 YAML 不变，yaw 限制不变。试验只覆盖前向，不构成
   横移、后退或转弯停止资格。
2. 保留四足支撑捕获，以及进入捕获第一帧的 PD+前馈总力矩等价。
   捕获后不再强行拉回标准关节角度，而保持捕获时的腿部几何，并使用
   行走前已验证的安静站立力矩参考补偿承重：
   `q_final = q_capture + tau_standing_reference / kp_standing`。
   已有动态力矩与关节速度记忆仍分别在 0.30/0.10 秒内平滑消退。
3. 捕获后的目标/增益过渡从 2.0 秒改为 0.5 秒；这只是动作过渡，
   **不是**把连续停稳确认改短。达到过渡末端后，仍须重新满足完整
   0.5 秒停稳条件才能开始收臂和下降，不能靠计时直接趴下。

估计器、四足承重候选、h−2σ / v+2σ、最低高度 0.48 m、倾斜限制、
速度 <0.04 m/s、gyro <0.18 rad/s、关节速度 <0.55 rad/s、关节漂移
限制、8/14 秒失败关闭及故障后拒绝下降逻辑均保留。
机械臂在捕获阶段维持最后命令；只有停稳许可后才走原有收臂/下降流程。

## 对照结果

0.3 m/s 指令、4 个不同按 B 时刻，各指标取这 4 项中的最大值：

| 指标 | 原版本 | 当前候选 |
| --- | ---: | ---: |
| B 到捕获站姿 | 2.535 s | 1.135 s |
| B 后整个过程最大水平位移 | 0.4721 m | 0.2150 m |
| B 到开始收臂/下降 | 7.955 s | 4.845 s |
| B 到趴稳并完成末尾 2 s 确认 | 13.960 s | 10.850 s |

0.2 m/s 同样四项对照：最大水平位移 0.2440 → 0.1179 m；
开始收臂/下降最大等待 7.245 → 4.555 s。

**并非所有指标都变好：**在上述 0.3 m/s 四项中，真值速度 <0.04 m/s
并持续四足支撑 0.5 秒的最晚首次时刻是 2.78 → 3.04 s，最大倾斜
是约 1.94° → 2.65°。因此结论是减少继续前进和无必要姿态切换、缩短
允许收臂的等待，不能宣称更快绝对静止或更平稳。仍有小幅过渡运动，
不能直接当成实机刹停性能。
