# VD12：补齐整枪避碰约束

日期：2026-11-14。下文保留本地实现检查阶段记录；随后正式6000轮训练已启动，固定2000轮真实Isaac Play结果见[阶段评估](VD12_2000_PLAY_REVIEW_20261114.md)。**有避碰进展，尚未验收或部署**。不要重复执行下文已经完成的实现检查。

## 结论

VD11的问题不只是MuJoCo显示错误：训练允许枪穿过自身，原来依赖接触力的终止无法发现关闭自碰撞后的自相交。此次在独立VD12任务中补上明确的几何禁区、净隙惩罚与回合终止，保留VD11及全部旧数据。

原工作目标暂不需要改。离线逆解找到两条完整2秒下放参考路径，均有满足关节限位、整枪避碰及离地要求的解。但这只是名义条件下的离散可行性检查，不代表旧actor已经会做，也不保证动态训练成功。

下一步固定VD12配置充分训练；不再用短训效果决定频繁改奖励。训练结束后先验收无自相交，再比较左右振荡、四足落脚冲击和跟踪效果，不能仅凭回报平台或跑满时间发布。

## 本次改动

- 保留2.93 kg、外径56／内径52 mm、长1100 mm新枪及既定安装、TCP、工作距离；保留驱动增益、速度限制、命令生成与域随机化。
- 保留VD11的枪尖高频运动与真实落脚冲击奖励；只增加整枪几何规则，启动阶段也生效。
- 用整枪胶囊包络与URDF已有机器人碰撞体检查44对净隙下界。固定子链接折叠到实际保留刚体，不能漏掉尾部或脚；枪所附着的同刚体`link06`整体排除。
- 净隙下界低于30 mm开始惩罚；低于0定义为保守禁区违反。成本为`min(9, (max(0, 0.03-lb)/0.03)^2)`，净隙奖励权重−1，失败奖励权重−100。Isaac奖励乘20 ms，因此一次失败项为−2，而非−100。
- 每5 ms读取真实刚体link位姿；锁存4个物理子步的违规，在原20 ms回合边界终止。没有启用全自碰撞、伪造接触力或向70维actor添加几何／世界真值输入。
- VD12保存几何profile与模型／几何源码SHA；同版续训必须一致，并恢复策略、AMP、优化器、轮数和课程。首次迁移只从VD11加载策略／critic和AMP，重置优化器、轮数及高位到地面课程。

这里的负下界是保守禁区违反，不等于真实穿透深度或接触力。终止最多等待原20 ms边界，不是5 ms即时物理阻挡。规则只覆盖URDF已有碰撞形状，不证明未建模视觉外壳或连续扫掠安全。
