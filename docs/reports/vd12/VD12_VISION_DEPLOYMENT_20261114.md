## 实际链路

前相机RGB → RHANet中心线 → 标定投影和后深度测得的平面 → 底盘速度命令。

后相机RGB＋对齐光轴Z深度 → RHANet可见中心线 → 后随0.80m工作点／明确标记的短期估计 → 完整枪体端面净空修正 → TCP目标。

这些数值命令与关节／IMU／上次动作组成原70维输入，进入同一70→18 actor，输出18维关节位置目标；不把图像直接送给actor。`ideal_front_command`、世界焊缝和MuJoCo位姿不参与命令生成。世界状态只用于独立评价和安全保护。

采用既有记录的相机内外参，renderer和图像metadata一致；新枪自遮挡mask来自采集时刻六轴编码器、固定URDF网格及相机标定，不来自仿真分割真值。11月15日已修正长枪跨相机近裁面的轮廓漏遮：先对凸包做近面裁剪，再投影排除管身；近面取renderer实际值，本样本约0.07m，不直接沿用旧0.08m常数。仅排除像素，不补出遮挡区的焊缝。

## 遮挡与时效

- 复用已存在的 `cross_sections` 可见截面中心法，不连接被枪遮住的像素。
- VD12显式启用逐组件工作点支持校验：原图像锚点候选合格时保持不变；不合格时，对其他单个可见组件分别执行原RGB-D、深度比例、12cm路径、工作包络及有界估计校验。仅选择一个合格组件，候选诊断保存在每帧包中，不将分开的可见段拼成长路径。旧VD5默认仍按原图像锚点选择。
- 显式开启原有0.60秒已观测路径缓存，按**此前发送的底盘命令**传播坐标；这不是实测里程计，存在速度跟随／侧滑误差。来源时间从原始capture计算，重复读帧不能续期。
- 历史缓存默认必须按原规则覆盖工作点，不默认向历史路径外再作切线估计。新增 `--historical-tangent-estimate` 仅供显式差分诊断；仍受原年龄、运动、间隙、0.25m范围及8点／12cm／P90≤8mm／最大残差≤15mm约束，输出标记为历史估计，不计当前测量。拟合验证与目标生成使用同一条拟合线，并重新检查实际外推距离。
- 近场最多0.25m可见切线估计；远端局部直线拟合最多0.05m，沿用至少8点／12cm支持及P90残差8mm等原有条件。不能满足则拒绝，不补虚假深度。
- 所有估计明确记录 `target_estimated`、`rear_target_directly_observed`、来源与原始age；历史路径的 `measurement_valid=False` 不计为当前观测。没有设定值hold。
- 采集时间在渲染前记录，推理前后检查原时间，不更新旧帧timestamp；私有发布历史校验generation／sequence／前后配对。分别核对墙钟、仿真时钟及历史目标原始来源年龄。最大capture年龄1秒沿用原视觉链，不代表1秒延迟满足最终控制精度。
- 25Hz只是图像请求频率，实际采集节拍见账本；RHANet吞吐及墙钟开销如实保留。命令仍50Hz、物理200Hz，同帧在未过期时可复用，但不计为新帧。
- 不可被上述有界观测支持的视觉失败／超时会在下一次actor和物理步前结束本地仿真。不是实机紧急制动保证。

关闭历史路径和远端估计作差分诊断：

```bash
bash scripts/deploy_vd12_vision.sh --viewer --vision-window --duration 30 \
  --rear-path-memory-s 0 --rear-occlusion-extension 0
```

`--vision-mode classical` 仅为明确的暗色胶带像素诊断，不是RHANet失败时的自动回退，也不代表学习型识别通过。

## 接入时发现并修正的命令差异

旧VD5视觉前端的heading只含可见路径切向角，遗漏训练使用的横向收敛项。平行路径偏移0.10m时，旧命令yaw约0，训练公式约0.248rad/s。VD12层补齐 `wrap(tangent_heading - atan2(lateral_error, 0.6))`，保持原1.5增益、曲率前馈和±0.8rad/s上限；不改旧VD5默认、不调执行器、不改策略／奖励。

前视稳健拟合还存在“最小中值残差候选支持不足就直接失败”的情况。VD12在该候选失败时尝试其他有足够实测内点的候选，沿用原最佳候选残差容差、至少半数内点与0.30m支持，不扩大误差门槛。实际旧失败帧及VD5默认不变均有回归。

后视seq94的逐组件离线复核确认：原锚点选中10.843cm短段，而同一图像的另一组件提供22.561cm连续实测路径（23点，x[-1.1055,-0.8846]m，网络置信度0.9973）。后者通过原target helper，近场估计10.246cm＜原25cm限制；这是更换组件选择的依据，不是降低12cm门槛。该工作点仍是估计，不能称为直接看到枪尖目标。

另一差异仍明确保留：2秒启动采用编码器FK的**机身系起点**，没有实测里程计时不冒充训练的WORLD固定起点。采用归一化姿态插值与完整1100mm枪体／实测平面法向的5mm净空规则，不把地面中心线直接当作枪端面中心。
