# VD6 actor 闭环输入与 joint1/6 振荡归因

2026-11-11。接续 [执行器诊断](VD6_ACTUATOR_DIAGNOSIS_20261111.md)，本轮完成约定的两项工作：已有日志闭环时序分析、离线 actor 输入敏感性分析。没有运行新物理仿真、训练、动作滤波或增益调整，没有替换 actor 或连接机器人。

## 主要发现及其边界

优先排查链路收敛为：**步态/横滚与 joint1 响应 → actor 的 joint1 反馈关系 → joint1 位置/速度耦合至 joint6 目标 → 横向枪尖运动**。

这是一条由离线证据支持的待验证链路，尚不是已确认根因。具体证据：

1. VD6 MuJoCo 0.80 m，joint6 目标高频变化中，joint1 速度与位置输入的有符号协方差份额分别约 49.9%、19.2%，合计约 69.1%；joint6 自身速度不是首要正向贡献项。
2. 把**完全相同的记录观测**送入 VD5 与 VD6 做局部导数比较，VD6 的 joint1 自位置负导数绝对值约减半，自速度负导数绝对值减少约 29%，上一帧 joint1 动作导数增加约 17%。这不是把不同引擎状态简单相减，也不表示源物理 PD 被改动。
3. MuJoCo 0.80 m 的 joint1 速度 RMS 从 VD5 的 0.175 增到 VD6 的 0.447 rad/s；横滚角速度 RMS 从 0.057 增到 0.127 rad/s。VD6 的横滚输入局部导数反而较小，故不能用“VD6 对 IMU 增益更大”解释该通道贡献增大。
4. Isaac joint6 速度尖峰确实被 actor 采到，并造成指令跳动；但是在 MuJoCo 0.80 m 的 5–15 s 窗口，joint6 没有超限速度样本，目标振荡依然更强。该尖峰可以解释 Isaac 的部分目标跳变，不能直接解释 MuJoCo 持续横向退化。

“负反馈减弱”在这里仅指**固定其他输入时，actor 输出目标对该输入的局部负导数变小**。闭环还有腿、IMU、上一帧动作、关节耦合和物理延迟，不能把局部导数直接当成完整闭环阻尼或稳定裕度；也不能据此直接加 PD、削减某个观测或替换编码器速度。

## 数据与输出复现

使用上轮已索引的八段原始会话：VD5 4498 / VD6 4997、Isaac / MuJoCo、0.70 / 0.80 m，速度指令均为 0.20 m/s。actor 归因窗为 5–30 s；原 30 s 会话最后一帧为 29.98 s，60 s 会话包含 30.00 s，因此分别有 1250/1251 个目标增量样本。没有用不同日志拼接物理轨迹。

每段在分析前验证原策略文件 SHA256。VD5 使用原训练 checkpoint 的 actor 权重，验证其输出与原 TorchScript 会话相符；VD6 使用 manifest 指定的 checkpoint。

- 八段共 10004 个 20 ms 目标增量样本；复现还覆盖每段从 0 s 起的原始 actor 样本。
- 全部 actor 动作最大绝对复现误差 `4.292e-6`，对应 0.25 动作缩放后的目标差约 `1.073e-6 rad`。批量 float32 网络求值可能有浮点累加差异，没有宣称逐位相同。
- `observation[52:70]` 与前一个日志动作裁剪后的值对齐，最大差为 0；因此“上一帧动作”没有错位。
- 用 200 Hz 日志的 **t 时刻步末状态**对齐 actor 的 **t 时刻步前观测**，joint6 速度最大误差不超过 `4.77e-7 rad/s`。没有插值、平滑、修正或用角度差分替代 actor 速度。

## 归因方法与校验

对每个相邻真实观测 `x(t-20ms)` 和 `x(t)`，沿它们之间的直线积分 actor Jacobian，将目标变化分解到 70 个输入维度；输出始终乘以原动作缩放 0.25。使用双精度与自适应 Gauss–Legendre 积分（本批最终为 256 点），不依赖一次局部线性近似解释大跳变。

该直线只是数学归因路径，不代表机器人实际经历了中间状态。输入相关性和路径选择会影响归因分配。各通道可能互相抵消；有符号份额可能为负或超过 100%，不能称为导致枪尖抖动的因果百分比。

- 70 个贡献求和与实际目标增量的最大残差为 `1.270e-6 rad`。
- 128→256 点各维贡献最大变化为 `1.765e-6 rad`。
- 积分各维目标增量得到分量序列，再作 3 Hz 高通并去除两端各 1 s，用于**目标高频能量**分析；重构最大残差为 `5.60e-7 rad`。
- 所有事件时序使用未经滤波的目标增量和归因贡献。高通结果不用于判断接触先后。
- 另做实际单位的小扰动检查，例如角速度 ±0.01 rad/s、关节角 ±0.001 rad、关节速度 ±0.1 rad/s；只在离线网络副本中求值。

## joint1 如何耦合到 joint6

下表为 0.80 m、5–30 s 的**关节目标高频 RMS**，单位 rad；不是枪尖 RMS，也不是实际关节角 RMS：

| 策略/引擎 | joint1 目标 | joint6 目标 |
| --- | ---: | ---: |
| VD5 Isaac | 0.01324 | 0.01893 |
| VD5 MuJoCo | 0.01665 | 0.01106 |
| VD6 Isaac | 0.01446 | 0.01005 |
| VD6 MuJoCo | 0.02579 | 0.02047 |

VD6 MuJoCo 的 joint6 目标高频能量分解：

| 输入 | 0.70 m 有符号份额 | 0.80 m 有符号份额 |
| --- | ---: | ---: |
| joint1 速度 | 52.1% | 49.9% |
| joint1 位置 | 17.7% | 19.2% |
| joint6 位置 | 13.4% | 13.7% |
| 上一帧 joint6 动作 | 9.4% | 11.6% |

上一帧动作本身由此前传感器和 actor 产生，不能把它当成独立外部根因。这里观察到的是一个跨时刻反馈通道。

同一 VD6 MuJoCo 0.80 m 观测集上的目标导数中位数：

| 输入→目标 | VD5 actor | VD6 actor | 解释 |
| --- | ---: | ---: | --- |
| joint1 位置→joint1 目标（rad/rad） | -0.5568 | -0.2829 | 局部负导数绝对值减约 49% |
| joint1 速度→joint1 目标（rad/(rad/s)） | -0.0540 | -0.0381 | 局部负导数绝对值减约 29% |
| 上一帧 joint1 原始动作→joint1 目标（rad/action） | 0.0494 | 0.0578 | 增约 17% |
| 横滚角速度→joint1 目标（rad/(rad/s)） | 0.0954 | 0.0729 | 减约 24% |
| joint1 位置→joint6 目标（rad/rad） | -1.0020 | -1.0776 | 跨关节耦合仍强 |
| joint1 速度→joint6 目标（rad/(rad/s)） | -0.0340 | -0.0361 | 跨关节耦合略强 |

0.70 m 同样呈现 joint1 自位置/速度局部负导数减弱，比例约为原来的 50%/69%。两个 actor 都只是在同一份日志输入上求导；VD5 在 VD6 轨迹上的输出属于离策略诊断，不是 VD5 在该状态下的真实闭环轨迹。

这些结果解释了为什么不能只盯 joint6 自身执行器：joint1 响应增大可以通过原本就很强的位置/速度耦合进入 joint6 目标。joint1 目标又受到后腿状态、上一帧动作和横滚共同影响，尚需物理干预才能确认哪个环节最先失稳。

## 落脚附近的实际时序

仍采用至少 60 ms 腾空、随后至少 10 ms 连续 >10 N 接触的定义。每次事件以**触地之后第一个 actor 样本**为参考，实际采样延迟另存为 0–20 ms；不会把 actor 时刻向前移动到接触时刻。

VD6 MuJoCo 0.80 m，FL/FR/RL/RR 的事件均值中，joint6 目标增量绝对值峰分别在该参考样本之后约 80/80/120/60 ms。joint1 峰分别为约 80/-40/0/60 ms。joint1 在部分脚触地前已有变化，且对角足事件邻近，因此不能把所有振荡起点归到某只后脚。

具体例子（仅展示一个高冲击事件，不替代总体统计）：原 VD6 MuJoCo 0.80 m 会话 RL 于 **8.545 s** 触地，后 40 ms 采样力峰约 **674.3 N**。

| actor 时刻 | joint6 目标变化 | joint1 速度贡献 | joint1 位置贡献 | joint6 自速度贡献 | 横滚贡献 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8.580 s | +0.0214 | +0.0157 | +0.0118 | +0.0012 | -0.0127 |
| 8.700 s | -0.0225 | -0.0170 | -0.0023 | +0.0028 | +0.0001 |
| 8.720 s | -0.0200 | -0.0137 | -0.0116 | +0.0037 | -0.0002 |

单位均为 rad/20 ms；这里只列四个输入，完整 70 维求和才等于总变化。该例中横滚在 joint6 输出中有抵消作用，而在 8.580 s 的 joint1 输出中贡献约 +0.0231 rad。这支持检查“底座/步态→joint1→joint6”的链路，但同一个闭环的时间相关和网络归因不能独立证明最初扰动来源。

## joint6 速度尖峰有没有进入 actor

以下是新 200 Hz 会话中 `5 ≤ t < 15 s` 的精确对齐；每组 2000 个物理状态、500 个 actor 样本，超限判据为 `abs(qd6)>3.1415+1e-4`。

| 策略/引擎、0.80 m | 物理超限样本数 | actor 实际采到的超限样本数 | actor 采样最大绝对速度 |
| --- | ---: | ---: | ---: |
| VD5 Isaac | 105 | 22 | 14.854 rad/s |
| VD6 Isaac | 25 | 3 | 4.204 rad/s |
| VD5 MuJoCo | 0 | 0 | 2.387 rad/s |
| VD6 MuJoCo | 0 | 0 | 3.1415 rad/s |

在 VD6 Isaac 的 3 个 actor 超限样本上，joint6 自速度通道对 joint6 目标增量的贡献 RMS 为 0.0262 rad，总目标增量 RMS 为 0.0298 rad，说明尖峰确实影响输出；样本很少，不能据此推断总体因果关系。

0.70 m 也显示 Isaac VD5/VD6 分别采到 16/3 个超限样本，MuJoCo 两版均为 0。因此不能通过将日志中未被 actor 采到的物理峰值直接代入网络，夸大它对真实策略输出的影响。

建议下一项物理实验：在两端使用原 actor 和原 160/5，在相同姿态/目标附近施加有明确幅度与时刻的小扰动，测量 joint1 的恢复、超调及 joint6 目标响应；先区分较弱自反馈与更强身体扰动的作用，再决定是否做适配修复或新训练。若采用底座横滚重放，必须让实际仿真运动生成 IMU 与编码器，不用人为替换的传感器数值充当部署结果。

本轮没有确认完整根因或问题解决，也没有开始上述物理干预。纯 PhysX 隐式驱动力矩/独立限速乘子的接口限制仍与前报告相同；它不妨碍本轮对实际 actor 输入输出的离线分析。
