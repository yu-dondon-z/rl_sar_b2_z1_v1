## MuJoCo 阶段对照

每个 checkpoint 在 0.70/0.80 m 各运行 30 s，200 Hz 物理、50 Hz actor、0.20 m/s 固定指令，5–30 s 统一窗口。VD5 4498 基线来自已完成会话：三轴高频 RMS 为 4.606 mm（0.70 m）和 5.797 mm（0.80 m）；足部竖直力峰 P95（FL/FR/RL/RR）分别为 [281.0, 310.2, 300.2, 297.4] N 和 [336.4, 288.0, 395.0, 286.4] N。

0.70 m 的早期模型虽然 RMS 低于 VD5，但速度较低且后腿冲击明显增大；训练末期 RMS 回升到 4.919 mm。0.80 m 只有中期 model_4800 接近 VD5（5.790 vs 5.797 mm），末期升至 6.879 mm；model_4600 和 model_5097 的后腿冲击也没有全面优于基线。没有一个 checkpoint 在两个距离同时改善抖动、速度和逐足冲击。

## 配方与产物

训练扰动是每个环境约 4–8 s 后随机触发、间隔约 5–9 s、持续 120 ms、身体 x 轴 ±4–10 Nm 的真实 PhysX 外力矩；actor 只通过实际 IMU/编码器看到后果。新增 `vd8_touchdown_force` 只在检测到四脚接触从 ≤10 N 到 >10 N 的窗口惩罚超过 300 N 的力，未使用 VD7 的 TCP 高通、持续承重或最差足峰奖励。接线 10/40 轮均通过，40 轮日志确认 `[VD8] First physical roll pulse` 已触发。

所有原检查点和 VD8 日志、阶段曲线、评估 stdout、源码快照位于 [VD8_REVIEW_20261111](../../../outputs/VD8_REVIEW_20261111)；新增训练说明为 `/home/dong/b2_z1_VD2/docs/archive/vd8/VD8_TRAINING_20261111.md`。必要单元测试 3 项及既有 VD6/VD7 测试通过，两个仓库 whitespace 检查通过。

本阶段结论：VD8 配方在 600 轮内没有形成同时改善机械臂抖动和落脚冲击的稳定候选。停止该配方的追加训练，不发布 model_5097 或中间 checkpoint；部署继续使用 VD5 4498，未同步板载、修改 PD、引入 actor 特权信息或启动机器人。
