## 可视化复核发现

- **枪体实际穿入底盘。** 用户回放2.005秒时，枪中心线有38.3 mm位于底盘主碰撞箱内部；5.005秒仍有14.4 mm。视觉枪管与碰撞圆柱同轴，并非仅显示mesh放错。
- **没有自碰撞阻挡。** MuJoCo机器人碰撞体为 `contype=2, conaffinity=1`，彼此不碰撞；Isaac训练模型也关闭自碰撞。枪—底盘相交不会产生对应接触力，因而“无接触终止”漏掉了这一错误姿态。
- **固定机身高度不是训练命令。** 回放按标称底盘高度0.50 m计算固定body-z；实际底盘降低并俯仰后，2–5秒目标world-z约为−77至−110 mm，而训练命令从世界焊缝按当前底盘位姿变换，不能这样固定高度。
- **机械臂持续贴限位。** 回放中joint2/joint3接近0 rad，枪被地面托住；最初高位姿态本身没有枪—底盘相交，随后下枪过程形成穿模。目前未发现关节排序错误，不能在纠正任务和碰撞验收前把问题全部归因于策略能力。
- **训练侧也有贴限位姿态。** 既有Isaac确定性probe的单个sample环境在2秒之后，joint2/joint3全程位于0±0.02 rad；joint2目标全部低于0下限，joint3目标约99.93%高于0上限。该环境世界目标高度均值约16.3 mm，并非MuJoCo的地下目标。因此不能承诺只修MuJoCo命令就能恢复合理抬臂，也不能将单sample扩大成全部32个环境的结论。

## 结论

VD11完成了6000次更新，最终为 `model_5999.pt`。虽有部分运动指标改善，但两端已确认枪体自相交，**当前策略未通过新枪几何验收，不部署**。下方原运动数值只作失败工况存档，不能作为物理有效运动的验收证据。

新枪模型和候选策略已接入独立MuJoCo诊断并执行30秒，但该工况现已确认存在自穿模和目标高度失真，不能称为有效运动验证，更不等于双视觉焊缝跟踪部署成功。VD5 `4498` 默认actor保持不变，没有板载同步或实机控制。

最初复核只使用已有结果；随后按用户要求新增了Isaac Play和纠正命令后的MuJoCo短回放，首次确证几何无效即停止。没有长训，没有调整奖励、驱动增益或接触条件。日志、检查点和默认导出全部保留。

## 3. MuJoCo 已完成什么

两版各完成30秒、6000物理步和1500策略步，无枪体支撑、非法接触或倾倒终止。均使用2.93 kg新枪及新TCP，checkpoint与URDF的SHA和记录一致。

这是**固定机身系目标的行走回放**：速度0.2 m/s、后方0.80 m目标、2秒渐入；没有相机、世界焊缝跟踪、随机复位或域随机化。世界真值仅用于记录和评估，不输入actor。

| 指标 | VD10 5998 | VD11 5999 |
| --- | ---: | ---: |
| 实际枪尖横向高频RMS（>3 Hz） | 0.385 mm | 0.261 mm |
| 实际枪尖横向低频RMS（0.5–3 Hz） | 1.447 mm | 1.629 mm |
| 横向低频跟踪误差RMS | 2.203 mm | 2.529 mm |
| 原始横向跟踪误差RMS | 4.903 mm | 6.839 mm |

| 左后腿落脚冲量p95 | 5.83 N·s | 7.53 N·s |

MuJoCo同样表现为高频横抖改善，但低频左右运动／跟踪变差，左后腿冲量增加。两版原始三轴跟踪误差分别为105.6和126.8 mm；跑满30秒不代表枪尖跟踪合格。

200 Hz日志包含引擎原生驱动力、原生约束和另列的限速冲量，不用PD估算冒充实际力矩。原生力对应步首求解，位置／速度对应步末，相差一个5 ms物理步；不能据此宣称已完成严格同相的跨引擎执行器归因。

## 4. 如何在 MuJoCo 查看候选

当前仅推荐使用[Play几何复核](VD11_PLAY_GEOMETRY_REVIEW_20261114.md)中的受保护诊断入口，看到`invalid_geometry`提前退出是如实拒绝穿模，不是训练成功。它不是正式双视觉部署。

**以下命令仅作问题复现存档，不再作为正常效果展示推荐。** 它会出现上述穿模和目标高度错误；在修正任务与碰撞验收之前，不要用它评价可用性。MuJoCo使用 `crack_vision` 环境；`env_isaaclab` 是训练环境，没有安装MuJoCo：

```bash
cd /home/dong/rl_sar_b2_z1
MUJOCO_GL=glfw /home/dong/anaconda3/envs/crack_vision/bin/python scripts/diagnose_vd11_gait.py \
  --checkpoint /home/dong/b2_z1_VD2/logs/rsl_rl/b2_z1_vd11_motion_quality_amp/2026-11-13_17-56-49_vd11_motion_quality_long_20261113/model_5999.pt \
  --command-mode legacy-fixed-body --viewer --duration 30
```

无界面运行时去掉 `--viewer` 并改为 `MUJOCO_GL=egl`；每次建立新输出目录，保留旧日志。已完成的数值评估无需为查看报告再运行一次。

入口：[diagnose_vd11_gait.py](../../../scripts/diagnose_vd11_gait.py)。最新入口默认使用世界焊缝命令并逐5ms检查几何；上方显式`legacy-fixed-body`才保留旧错误目标供复现。CPU测试只证明接入约束，不证明运动效果合格。

## 5. 后续决策

当前不替换默认actor，也不自动再启动训练。先修正新枪任务的物理有效性：核对目标/过渡可达且不穿自身，设计并验证枪与底盘/机械臂之间的选择性碰撞或明确的几何约束与终止；不能只在MuJoCo查看器开全自碰撞后宣称原策略修好。有效姿态成立后再评判左右摆动与落脚冲击。
