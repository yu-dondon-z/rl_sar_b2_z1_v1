## 已完成

### 1. Z1 指令按本地控制器回复节奏发送

`deployment/vd2_real/native/reply_paced_udp.h` 是真实 native IO 使用的传输子类。
原 SDK 控制器一次只接收一个数据报，独立标称 500 Hz 的发送和接收时钟会积压旧目标。
新版本每个完整控制器回复授予一个发送机会，使用当时最新目标；不保存中间目标队列。
缺回复时不重发活动位置指令，PASSIVE 转换立即发送，随后仅 PASSIVE 可按 20 ms 重试。

未更改 Z1 增益、B2 写帧节奏/映射或故障判据。回复只代表本地控制器消息，
不是命令确认，更不是电机采样时效。新增 native 发送时间、来源提交时间、
实际序列化臂目标及发送/跳过/回复计数，便于下一次抓包逐段对齐。

真实 `libZ1_SDK_x86_64.so` 配合真实控制器库的 `ARMSDK`，在新的回环端口回显，
接收周期故意为 2.2 ms、发送循环为 2 ms。复现旧 P95 约 180 ms、最大 188 ms；
修复后 P95 约 4 ms、最大约 4–5 ms。
没有构造真实机械臂的 IOUDP/FSM，没有访问 192.168.123.110 或正式 8071/8072 端口。
