# VD1 走偏／摔倒：隔离诊断（2026-11-03）

## 当前结论与边界

这是一轮本地诊断，不是已修复的部署版本。没有启动训练、同步板载或实机控制；没有改生产控制器、策略、增益、质量、碰撞或传感器。原日志全部保留。

固定末端目标、连续平地、禁用视觉闭环后，原 VD1 在 MuJoCo 和源配置 PhysX 中均能直行、左右转，直行各完成 60 秒。但速度标定、零速停车、模型转换、视觉闭环与起臂接触均有未通过项。不能把结果说成“底盘完全不会转”，也不能说“只要速度改成 0.4 就已匹配训练”。

最明确的事实：

- 指令 `vx=0.4 m/s`，平地 MuJoCo 实际约 **0.503 m/s**，PhysX 约 **0.334 m/s**（4–10 秒窗口）。两者不是严格等价动力学。
- 指令降至零并持续保持，MuJoCo 仍约 **0.437 m/s**（17–60 秒），PhysX 仍约 **0.289 m/s**（17–30 秒）。视觉丢帧后清零指令不等于物理停车。
- 固定末端目标时，`w=±0.15 rad/s` 在两引擎均产生相应转向，详见下表。
- 原三次失败的执行器目标已逐条重放，全部 20 ms 根位置逐样本误差为 **0.0 m**。枪在启动约 0.235 秒确实触地，但它不是三次晚期摔倒的共同直接触发因素。
- MuJoCo 有效总质量 82.258067 kg；本次源配置导入 PhysX 后 83.258062 kg。差额来自显式零质量的 `dummy_target` 在 PhysX **运行时回退为 1 kg**（USD中仍为零），必须核对有效模型，而不只是检查 URDF 数值。尚无原训练运行时质量dump，不能断言历史训练必然相同。逐刚体质量／惯性比较见 [专项核对](VD1_ISAAC_MASS_INERTIA_AUDIT_20261103.md)。

## 双相机闭环已有证据

尚未更改生产视觉逻辑：

- 前视、后视须同时有效；后视短线等拒帧会把本体期望速度和角速度同时清零，随后重新经过 2 秒启动渐进。策略只训练固定前向速度、未覆盖可靠零速站停；这两个设计不匹配。
- 第三次 27–34 s 指令速度均值约 0.049 m/s，而世界 X 实际均速约 0.379 m/s；“日志指令很小”并不代表走得慢。
- 前视直接在机身 XY 拟合和计算转向，未用 IMU 去除 roll/pitch；训练本体命令采用 yaw 水平坐标。小幅机身起伏可能污染几何量，尚需独立消融验证，不能把它直接说成已证明的唯一根因。
- 相机帧龄有效段约0.28 s，存在大于0.5 s；允许最长1 s采样保持，没有自运动补偿。不得通过改时间戳或放宽时效伪装新鲜帧。
- 第三次2 s后约58.1%末端目标经过工作空间裁剪，y达到-0.15。说明相机后环／底盘相对路径存在持续偏差，但固定边界目标实验表明它不单独导致“完全不会转”。
- 第一次11.24 s倾斜已超过8°，视觉仍有效，`v=.4`、`w≈.004`；首次invalid约11.46 s。不能把该次失稳起点全归因于视觉拒帧。
