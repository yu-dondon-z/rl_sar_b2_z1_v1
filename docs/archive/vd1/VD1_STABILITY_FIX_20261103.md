# VD1 双视觉突然失稳：修正与实际运行

**后续更新：**当前F5已切换为“后RGBD测焊缝→直接生成末端目标→原actor”，取消后视工具标记与视觉TCP误差反馈，场景不再生成彩色标记球。曲率仍为0.30/m、速度指令仍为0.4 m/s。新实现与检查记录见[无标记调试说明](VD1_SEAM_ONLY_DEBUG_20261103.md)。下文保留此前依赖视觉TCP的实现与运行历史。

当前双视觉调试默认曲率已从0.40/m降至0.30/m，脚本与VS Code F5同步更新。原因是用户反馈0.40/m第二个弯顶仍未通过；本次仅降低场景曲率，做参数转发检查，尚未验证0.30/m的完整行走表现。下文0.10/m与0.40/m数据为历史运行记录。

本文60秒运行数据对应最大曲率0.10/m。按后续要求，双视觉调试默认已提高到0.40/m（4倍），将高度场Y覆盖范围扩至[−1.75,1.75] m，并将X采样间隔细化至2.5 mm；下述数据不代表新曲率已完成60秒验证。

0.40/m后续修正与22秒检查见本文末尾：修正前视选错线段，急弯引导距离自适应缩短至0.4 m，配对引导的角速度滤波时间常数改为0.12秒。该次底盘横向误差最大4.13 cm，全程没有进入stopped；尚未完成新曲率60秒检查。

默认F5入口仍是“VD1：双视觉＋同形裂缝（MuJoCo 调试）”。本次修改接入了连续路面碰撞和前后视近距离引导。最终真实RHANet双视觉运行完成3000步／60秒，世界X净前进29.2654 m，最大倾斜6.0319°，未摔倒、未进入stopped。相邻较早一次完整检查有0.6秒保护减速后恢复，故仍需保留后视丢失的恢复逻辑，不能保证每次无减速。

## 失稳记录提供的证据

用户最新失败记录：`outputs/VD1_DUAL_VISION_DEBUG/session_20261103_161014_hb98o2bz/`，10.18秒`IMU_tilt_stop`。对应离线重放与编码器最大误差5.86e-8 rad，结果位于`outputs/VD1_VISION_COMMAND_AUDIT/audit_20261103_161408_9dkbn4_t/`。

- 0–6秒前视路径的平均世界XY几何误差约3–4 mm，地面法向误差约0.06°。
- 6.86秒足端圆形投影首次侵入裂缝边缘；这只是水平几何评价，不能据此直接称为沟壁承力接触。
- 8.10秒倾斜已超过8°，命令仍有效且vx约0.4，末端目标y约−0.149 m；首次无效控制发生于9.56秒。不能把起始失稳归因于停车触发。

原前视控制追逐距离机身约1.5 m的可见近端，对已经形成的近身偏差纠正不够。新增前后视拟合后，16秒实际检查最大倾斜5.49°，但保留旧棱柱接触的完整检查仍于18.68秒摔倒。该次接触重放编码器误差5.65e-8 rad，13.73秒首次超过8°之前一秒无枪承力接触；晚期18.13秒才出现枪承力。记录：`outputs/VD1_VISION_COMMAND_AUDIT/audit_20261103_162135_h6vcimqe/`。

## 路面碰撞是独立问题

隔离掉视觉，使用真值路径和原actor，保留物理沟槽：9.94秒仍然摔倒。此前真值曲线60秒成功使用连续平面，与物理裂缝不同。新对照保存在`outputs/VD1_TRUTH_CURVE_DEBUG/physical_isolation/truth_curve_20261103_162221_9j4ohnwk/`。

进一步对原弯道凸棱柱进行足端半径32 mm的接触探针扫描。在离裂缝20 cm、球心Z=18 mm时，理论水平顶面穿入14 mm；一些棱柱接缝给出的穿入仅约0.377 mm，法向水平分量约0.822。原先仅在Z=30 mm、少量位置进行的接触检查没覆盖这一情况。这是明确的碰撞几何／接触计算缺陷，能产生错误横向反作用。它不证明所有历史摔倒都只有这个原因。

`vd1_mujoco_road_contact.py`保持原视觉网格，仅更换道路接触：X∈[−25,35] m、Y∈[−0.75,0.75] m内使用共享采样的高度场窄块；外侧和远端直线段为箱体。分块避免单高度场与足端之间的接触数限制。裂缝顶面开口仍为2 cm、底部深5 cm，侧壁含约2.5 mm的离散斜坡；这不是与原竖直壁完全相同的碰撞表示。网格X间隔1 cm、Y间隔2.5 mm。各文件编译归一化后补偿绝对高度，防止外侧浅坡块被拉深；格式和归一化规则见[MuJoCo 3.2.3高度场文档](https://mujoco.readthedocs.io/en/3.2.3/XMLreference.html#asset-hfield)。原机器人碰撞、质量惯量、PD、策略与速度约束未改。

新增物理回归检查旧异常位置与实际穿入深度、曲线正负两侧沟槽深度／边沿、机器人动力学以及原渲染几何。查询透明碰撞层射线时，仅把测试模型的碰撞层临时设为不透明，不影响运行模型。

## 图像到控制的修正

`vd1_visual_path.py`只读取同步且已通过后视连续性检查的前后视路径与RGBD测得地面，不读取真值。将路径投影到测得地面的前／左坐标，对两个可见区段作等权局部三次拟合，在相机不可见区域插值0.6 m引导点，沿用限幅、速度滤波和原actor。拟合有残差、曲率、覆盖范围检查。失败时回退到独立有效的前视可见点；后视短暂丢失继续沿用原rear_hold保护。没有新增真值兜底或图像运动补偿。

控制状态包含`front_steering_method`、`guidance_fit_p95_m`、`guidance_lookahead_xy_ground_m`、`guidance_gap_is_interpolated`与拟合拒绝原因。捕获坐标中的`front_lookahead_b`和测得地面坐标中的引导XY分开记录。`--front-only-guidance`可对照旧引导，`--road-contact prisms`可对照旧接触。

## 0.40/m急弯：前视误选与转向响应

用户运行`outputs/VD1_DUAL_VISION_DEBUG/session_20261103_173617_t3awvrrc/`在12.64秒首次拒绝控制，随后逐渐偏离。对完整记录的关节目标离线重放，与记录编码器最大误差2.80e-8 rad。中断导致视觉gzip缺少结束标记，诊断只在RAM副本中读取261条完整记录；原文件保持只读。

12.48秒前视路径平均世界XY误差约7.6 mm；12.56秒检测切换到错误线段，平均误差1.749 m，前视X覆盖只有0.17 m，触发最小支持检查。12.60秒错误段覆盖变长，又能给出正0.109 rad/s转向，与真实裂缝所需方向相反。此前底盘误差仍在几厘米内。不能将后续偏离只归因于转向限幅不足或盲目增大增益。

- 本仓库`vd1_visual_front.py`在原RHANet分割后，对连接组件分别提取中心线，用测得地面和相机标定计算前向覆盖，选择有效前向覆盖最长的组件。原固定图像中心锚点在裂缝偏到画面一侧时容易选到错误短线。保留原置信度、长度、ROI和后视处理；仅`guarded`入口通过本仓库桥接包装接入，`original`对照仍使用上游桥。没有读取世界姿态或解析曲线。最长覆盖不是通用误检保证，连续的长错误线仍可能被选中。
- 配对三次拟合在机身处计算局部曲率，正常引导0.6 m；曲率超过0.15/m后逐渐缩短，最短0.4 m，加强急弯横向纠偏。没有额外叠加曲率前馈。
- 配对视觉引导有效时，角速度滤波时间常数从0.20秒改为0.12秒，减少转向滞后；速度／失效减速仍为0.20秒，转向限幅仍为±0.8 rad/s，后视保持和恢复条件不变。

短程实际RHANet检查：`outputs/VD1_DUAL_VISION_DEBUG/sharp_steering_checks/session_20261103_174823_0ojj_z7k/`。0.40/m物理裂缝、0.4 m/s速度指令、原actor与PD，完成1100步／22秒，越过第一弯顶并下行至X约9.74 m。底盘横向误差P95为3.83 cm、最大4.13 cm；最大倾斜6.01°；tracking 1067步、rear_hold 33步、stopped 0步，无运行错误。TCP误差P95为7.52 cm、最大9.44 cm，末端精度仍有改进空间；足端边缘最小水平裕量仍为负。
