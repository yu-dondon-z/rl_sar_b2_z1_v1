# VD1 MuJoCo 特权真值曲线调试

这是用户要求的独立特权信息实验：用世界坐标真值点构成平缓曲线，读取 MuJoCo 的真实机身位置与姿态生成底盘速度及末端目标指令，观察原 VD1 actor 的闭环运行效果。没有相机分割、检测延迟或拒帧。

双视觉与同形物理裂缝版本已提供独立F5入口 **VD1：双视觉＋同形裂缝（MuJoCo 调试）**，操作见[双视觉调试说明](VD1_DUAL_VISION_DEBUG.md)。

## 在 VS Code 中运行和观察

1. 打开项目 `/home/dong/rl_sar_b2_z1`。
2. 左侧选择“运行和调试”，下拉选择 **VD1：真值曲线（MuJoCo 可视调试）**，按 **F5**。
3. MuJoCo 原生窗口打开后处于暂停状态，点击窗口并按 **空格** 开始；再次空格暂停／恢复。鼠标旋转／缩放视角；关闭窗口或集成终端 Ctrl+C 退出并保存记录。
4. VS Code 集成终端每秒打印速度指令、实际速度、机身与TCP曲线误差及倾斜。可在 `scripts/debug_vd1_truth_curve.py` 中的 `controller.update(...)` 后设断点，查看 `command`、`tool`、`guidance`，之后查看70维 `observation` 和18维 `action`。

F5 的3D画面由 MuJoCo 单独窗口显示，不嵌入 VS Code 编辑器。若希望直接在编辑器内看图，选择 **VD1：真值曲线（生成 VS Code 轨迹图）** 后按 F5；打开终端打印的 `trajectory.svg` 即可用 VS Code 图片预览查看。SVG 每1秒仿真时间更新，最终保留完整轨迹；预览是否自动刷新由编辑器决定，必要时重新打开。XY图的两个坐标轴分别缩放并标注单位，以便看清当前约34 cm振幅的曲线。

终端也可运行：

```bash
cd /home/dong/rl_sar_b2_z1
bash scripts/debug_vd1_truth_curve.sh
```

慢动作：`bash scripts/debug_vd1_truth_curve.sh --realtime-factor 0.5`。

无窗口生成轨迹：`bash scripts/debug_vd1_truth_curve.sh --headless`。

固定末端对照：`bash scripts/debug_vd1_truth_curve.sh --tool-mode fixed`。此项仍用真值曲线引导底盘，但末端命令保持原录制目标；默认 `--tool-mode curve` 会让末端横向目标跟随曲线。

## 画面含义

- 青色线与离散点：世界坐标真值曲线，点间距约5 cm；前2 m直线，2–22 m为平滑 `sin³` S曲线，随后恢复直线，默认最大曲率0.10/m，相比原0.05/m增大一倍，横向振幅约34 cm。
- 黄色点与连线：底盘0.6 m前视目标。
- 橙色轨迹：机器人机身实际行走轨迹。
- 绿色点：当前末端指令转换到世界坐标的位置；绿色线连接真实TCP与该指令。
- 粉色点：真实TCP；地面粉色轨迹为其垂直投影。

显示用模型／数据与控制用模型／数据分开，鼠标交互、标签和轨迹均不改变控制物理状态。

## 控制契约和实验边界

- 默认60秒，速度指令前2秒渐增到0.4 m/s。真值曲线经基于真实机身位姿的 pure pursuit 转换为原有3维底盘速度命令；角速度限幅±0.8 rad/s。
- 末端命令仍为7维XYZ＋wxyz姿态。默认在机身坐标系后方x=-1.02 m与真值曲线求交，生成横向目标；保留训练工作高度z=-0.30 m、原录制姿态、工作空间限制和目标过渡限速。地面曲线不是要求TCP本体贴地。
- 真实TCP仅用于评估和显示，未用于末端指令反馈。特权来源是世界路径和真实机身位置／姿态。actor仍接收原70维观测，输出18维动作；没有增加世界速度观测、IK关节控制、外力或位置传送。
- 使用原VD1策略与URDF、50 Hz actor、200 Hz PD、5 ms物理步长及已有实验性 `impulse` 限速／Z1隐式位置转换。未修改生产视觉控制、训练、质量或增益。
- 场景为连续平面；参考曲线只在显示层绘制，不生成物理裂缝或沟槽。因而这不是此前物理裂缝地面的完整复现，也不证明两引擎动力学等效。
- 这是新的真值外环对照，不是对上游相机投影命令器的逐行复刻，不能将结果解释成原视觉外环已经修复。

## 输出

每次独立保存到 `outputs/VD1_TRUTH_CURVE_DEBUG/truth_curve_日期_唯一编号/`：

- `trajectory.svg`：可直接在 VS Code 中打开的实际轨迹图。
- `truth_curve.csv`：实际使用的世界坐标真值点。
- `tracking.csv`：实际速度、转向、倾斜、机身及TCP到折线的距离。
- `actor_trace.jsonl.gz`：每步命令、70维观测、18维动作，以及明确标记的特权信息来源。
- `evaluation_truth.jsonl.gz`：独立物理评估记录。
- `manifest.json`、`summary.json`：配置、哈希、终止原因及误差统计。

TCP误差定义为真实TCP垂直投影至z=0平面后，到真值折线的最短XY距离；不是TCP三维位置误差。汇总跟踪指标从2秒开始统计，倾斜最大值包含启动过程。
