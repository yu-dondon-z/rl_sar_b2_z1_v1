# VD1 无视觉平地行走可视调试

本地 MuJoCo 调试入口，不启动视觉、板载通信或实机控制：

```bash
cd /home/dong/rl_sar_b2_z1
bash scripts/debug_vd1_flat_walk.sh
```

窗口打开后暂停在初始状态。**点击 MuJoCo 窗口，再按空格开始；再次空格暂停／恢复。** 默认走满60秒仿真时间后退出。关闭窗口或终端 Ctrl+C 提前结束并保存记录。

鼠标可旋转视角、滚轮缩放；视点跟随机器人。显示模型和数据是独立副本，鼠标拖拽物体、界面物理参数等不会改动真正控制用的模型。窗口文字与一米网格仅供观察，不作为策略输入；终端每秒显示一次指令、真实机身坐标系速度与倾斜角（`EVAL ONLY`）。

慢动作查看足部（只改变墙钟节奏，不改物理步长／策略频率）：

```bash
bash scripts/debug_vd1_flat_walk.sh --realtime-factor 0.5
```
