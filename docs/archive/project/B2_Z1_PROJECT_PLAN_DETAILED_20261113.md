# B2＋Z1 焊缝跟踪项目整体实施方案（详细存档）

日期：2026-11-13。本文说明项目主线，不代表候选策略已验收或已部署。

## 一、项目目标

利用 B2 四足底盘、Z1 机械臂和前后相机，实现机器人沿焊缝移动、枪尖持续跟踪工作点的全身协同控制。

当前优先解决两项问题：**机械臂左右振荡明显、B2 落脚砸地明显**。改善这两项的同时，不能牺牲焊缝跟踪精度、枪轴方向和行走稳定性。

本阶段以感知、运动控制和仿真验证为范围；实际焊接电源控制、热过程及焊接工艺质量验收另行规划。

## 二、总体技术路线

项目分为离线训练和在线运行两条链路，训练完成后不在运行过程中更新策略。

```text
离线训练
实物参数 → 统一机器人模型 → Isaac Lab训练（PPO＋AMP）→ 候选策略

在线运行
前后相机 → 焊缝识别与几何计算 → 底盘速度命令＋枪尖位姿命令
                                              ↓
                              本体状态 → 全身策略 → 关节角目标 → 驱动执行

验证与发布
Isaac确定性回放 → MuJoCo动力学验证 → MuJoCo视觉闭环 → 经批准的实机验证
```

前相机主要提供底盘循迹依据，后相机提供工作点附近的焊缝信息。相机标定、深度和关节编码器正运动学用于生成可供策略使用的命令。

训练中可以利用仿真真值生成任务和计算奖励；实际视觉链路不能用世界路径、真实接触或过期帧伪装成当前有效观测。

## 三、实施流程

### 1. 统一实物与仿真模型

按实际设备确定质量、惯量、安装方式、碰撞形状和枪尖坐标，使 Isaac Lab 与 MuJoCo 使用一致的模型定义。

当前枪管规格为外径56 mm、内径52 mm、长度1100 mm、质量2.93 kg。枪轴平行机械臂末端朝向，夹环相对法兰中心局部上偏100 mm；夹环前伸900 mm为当前选定的建模值，后续以实物测量复核。连接件忽略质量。

**阶段产出：**固定版本的机器人模型、安装参数和 TCP 定义。旧枪与新枪结果分开记录，不能直接当成同条件对照。

### 2. 建立统一的任务命令

底盘和机械臂围绕同一条世界焊缝工作，而不是分别执行互不相关的随机任务。

- 底盘根据路径横向偏差、航向和曲率生成速度命令。
- 机械臂沿焊缝弧长后移0.80 m选取工作点，转换为机身系枪尖位姿命令。
- 起步时从实际复位位姿平滑过渡到目标，并保留真实枪体接地与倾倒终止。

训练采用理想几何命令，视觉验证采用实际图像生成命令；两者保持接口、坐标和单位一致，但不把理想输入视为真实视觉效果。

**阶段产出：**可复现的停车、直线和缓弯任务，以及一致的底盘／枪尖命令接口。

### 3. 进行全身策略训练

沿用现有全身策略框架：输入70维，包括底盘命令3维、末端命令7维、本体状态与上一动作60维；输出18维，控制12个腿部关节和6个机械臂关节。

策略输出的是关节位置偏移，不是直接力矩：

`q_ref = q_default + 0.25 × a_t`

策略以50 Hz运行，驱动和物理仿真以200 Hz运行；腿部采用显式PD，机械臂采用隐式位置驱动。

训练使用 PPO＋AMP，并结合任务奖励、运动平滑项和腿部镜像约束。重点同时约束枪尖左右运动和落脚冲击，不能只优化总回报。

训练节奏固定为：

1. 短检查只确认实现、启动和日志正常，不据此判断收敛。
2. 正式训练期间固定奖励和关键配置，完成充分训练后再评估。
3. 中止后从同版本完整检查点恢复优化器、AMP与课程；跨版本迁移单独记录。
4. 若进入稳定平台后仍未达到目标，再依据回放证据调整相关设计，避免反复短训、频繁改奖励。

**阶段产出：**完整检查点、TensorBoard日志、配置快照及候选策略，不直接替换部署基线。

### 4. 验证运动质量与仿真迁移

先在 Isaac Lab 中做无学习更新的确定性回放，再用同一候选在 MuJoCo 中验证。比较时固定新枪模型、任务条件和统计方法。

| 验收目标 | 主要依据 |
| --- | --- |
| 机械臂不明显左右摆动 | 实际枪尖左右运动与跟踪误差，分别检查低频摆动和高频抖动 |
| 四足落脚柔和 | 四条腿分别统计落脚峰值力、接触冲量和触地前下行速度 |
| 跟踪能力不退化 | 枪尖位置误差、枪轴夹角、底盘循迹误差及实际前进速度 |
| 运行可靠 | 真实终止事件、枪体触地、倾倒及完整任务完成情况 |

以现有代表性回放为主，不重复已经完成的同条件评估。若两端结果明显不一致，再针对性检查200 Hz关节响应、实际驱动力矩、约束活动、驱动与限速实现；PD估算力矩不能代替实际驱动力矩。

**阶段产出：**同条件对照报告。候选必须同时兼顾摆动、冲击与跟踪，不能仅凭路径投影误差或某一条腿改善判定成功。绝对工艺精度和硬件载荷门槛需另行确认，不能把奖励参数当成安全限值。

### 5. 验证 MuJoCo 视觉闭环

动力学表现合格后，接入前后相机、焊缝识别和几何命令生成，验证真实图像输入下能否连续工作。

重点检查枪体遮挡、焊缝误识别、工作点可见性、帧时效和命令连续性。失效图像按既定保护逻辑处理，不降低有效性要求来制造成功结果。

**阶段产出：**视觉闭环运行录像、有效观测与失效原因记录、实际前进距离及跟踪／运动质量报告。固定机身目标的动力学回放不能代替这一阶段。

### 6. 经批准后开展实机验证与发布

在模型、策略和视觉闭环通过仿真验收后，另行制定并批准实机测试流程。先核对真实传感器、标定、关节接口和时序，再开展受控运动测试。

发布时冻结模型、策略、标定、配置和回滚版本。仿真通过不等于实机安全或焊接质量合格；未经明确授权，不同步板载、不启动控制、不让机器人运动。

**阶段产出：**可追溯的发布包、运行说明和实机验证记录。
