# B2＋Z1 焊缝跟踪项目方案

## 项目目标

让 B2 沿焊缝平稳行走，Z1 带动枪尖持续跟踪焊缝。重点解决机械臂左右振荡和四足落脚砸地，同时保持跟踪精度。

## 整体流程

实物建模 → 策略训练 → 仿真验证 → 视觉闭环 → 实机验证

1. 建模：按照实际枪管尺寸、重量和安装方式，统一 Isaac Lab 与 MuJoCo 模型。
2. 训练：使用 PPO＋AMP 学习底盘与机械臂协同控制，固定配置充分训练，避免反复短训、频繁改奖励。
3. 仿真：在 Isaac Lab 和 MuJoCo 检查枪尖摆动、四足落脚冲击及焊缝跟踪效果。
4. 视觉：前相机引导底盘循迹，后相机确定枪尖工作点，验证连续跟踪。
5. 实机：仿真验收通过，并获得明确授权后，再开展实机测试与部署。

运行时，相机生成底盘速度和枪尖位姿命令，结合机器人自身状态，由全身策略输出关节角目标，驱动腿部和机械臂运动。

## 当前下一步
